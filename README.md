# Aplicação Gráfica Modbus TCP em KivyMD

Aplicação desenvolvida em Python/KivyMD para leitura e escrita de dados utilizando o protocolo Modbus TCP.

## Requisitos
- Python 3.9+
- Python deve estar na versão 3.12 (venv) ou anterior para rodar o kivy
- Dependências listadas em `requirements.txt`
